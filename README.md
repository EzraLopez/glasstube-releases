# GlassTube releases

Downloads and the update feed for GlassTube, a native macOS client for
YouTube and YouTube Music. Builds are signed with Developer ID and
notarized by Apple.

**Install:** download the latest `GlassTube-<version>.dmg` from
[Releases](../../releases), open it and drag GlassTube to Applications.
Later versions arrive in the app: GlassTube ▸ Check for Updates…

`appcast.xml` is the [Sparkle](https://sparkle-project.org) feed the app
reads. Every update in it is signed; the app refuses any that isn't.
